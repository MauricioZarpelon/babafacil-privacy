🔒 Política de Privacidade – BabaFácil

Última atualização: //2026

O aplicativo BabaFácil respeita a sua privacidade e está comprometido com a proteção dos dados pessoais de seus usuários. Esta Política de Privacidade explica como coletamos, usamos e protegemos as informações fornecidas ao utilizar o aplicativo.

📌 1. Informações que coletamos

O BabaFácil coleta apenas as informações necessárias para o funcionamento do aplicativo:

Nome da babá

Idade

Telefone (informado voluntariamente)

Cidade

Experiência profissional

Foto de perfil (opcional, enviada pelo usuário)

Esses dados são fornecidos diretamente pelo usuário no momento do cadastro.

🔧 2. Como as informações são utilizadas

As informações coletadas são usadas exclusivamente para:

Cadastrar babás na plataforma

Permitir que responsáveis encontrem babás por cidade

Exibir os dados cadastrados dentro do próprio aplicativo

❗ Não utilizamos os dados para fins publicitários
❗ Não vendemos, alugamos ou compartilhamos dados pessoais

☁️ 3. Armazenamento e segurança dos dados

Os dados são armazenados de forma segura utilizando os serviços do Firebase (Google):

Firebase Firestore – armazenamento dos dados cadastrais

Firebase Storage – armazenamento das fotos (quando fornecidas)

O Firebase adota padrões elevados de segurança para proteger as informações armazenadas.

📤 4. Compartilhamento de dados

O BabaFácil não compartilha dados pessoais com terceiros, exceto quando necessário para o funcionamento técnico do aplicativo por meio dos serviços do Firebase.

🧒 5. Conteúdo infantil

O aplicativo não é direcionado ao público infantil.

Embora o serviço esteja relacionado ao cuidado de crianças, o uso do aplicativo é destinado exclusivamente a adultos, como responsáveis e profissionais (babás).

Não coletamos intencionalmente dados de crianças.
